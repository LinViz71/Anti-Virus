# Проверка компьютера через ClamAV

Это окно запускает отдельный антивирусный движок ClamAV. Сам движок в папку проекта не включён.

## Первый запуск

1. Установите ClamAV для Windows с [официальной страницы загрузки](https://www.clamav.net/downloads). Для обычного 64-разрядного ПК выберите Windows x64 MSI.
2. Откройте `Запустить проверку.cmd`.
3. Нажмите **«Обновить базы»**. Для первой загрузки сигнатур нужно подключение к интернету.
4. Запустите **«Быструю проверку»** для загрузок, рабочего стола, временных файлов и пользовательской папки автозапуска. Для полной проверки выберите **«Проверить локальные диски»** (включая подключённые USB-накопители) или укажите папку.
5. После проверки список показывает обнаружения и ошибки ClamAV, включая сообщения из потока ошибок. Чистые файлы не перечисляются. Результаты собираются в памяти отдельно от файла отчёта, список ограничен 5000 строками.
6. Удаление доступно для выбранных обычных сигнатурных обнаружений только после подтверждения. Сначала программа по очереди открывает каждый выбранный файл, вычисляет его SHA-256 и убеждается, что ClamAV на содержимом этого же открытого файла снова находит ту же сигнатуру. Если хотя бы один файл не прошёл эту проверку, подтверждение не показывается и удаление не начинается. Затем диалог показывает проверенные пути и названия обнаружений. После согласия программа ещё раз открывает каждый файл, сверяет его SHA-256 с хэшем перед подтверждением, повторно проверяет ту же сигнатуру на содержимом открытого файла и только затем помечает именно этот файл на удаление. Во время обеих проверок доступны прогресс и отмена. Эвристики, PUA, фишинг и предупреждения о лимитах сканирования удалить из этого окна нельзя.

Если ClamAV установлен из ZIP в нестандартную папку, нажмите **«Найти clamscan.exe…»** и выберите файл из папки ClamAV. Обновлятор `freshclam.exe` должен лежать рядом.

## Что важно знать

- Перед полной проверкой программа считает файлы и показывает примерный процент обработки. Быстрая проверка начинает сканирование сразу и показывает число обработанных файлов без процента.
- Это проверка по запросу, не постоянная защита. В документации ClamAV указано, что сканирование при доступе поддерживается на Linux, но не на Windows.
- Сканирование всех дисков может идти несколько часов. Недоступные Windows файлы могут попасть в отчёт как ошибки; в таком случае результат неполный.
- ClamAV проверяет поддерживаемые архивы и документы. Зашифрованные объекты или объекты, превысившие безопасные лимиты движка, отмечаются для внимания, но содержимое может быть не проверено.
- У сканера нет универсального процента обнаружения для любого компьютера. Он ищет известные угрозы по сигнатурам и применяет эвристики, но новые, изменённые или скрытые угрозы может пропустить; недоступные, зашифрованные и превышающие лимиты файлы также мешают полной проверке.
- Возможны ложные срабатывания даже у сигнатурных обнаружений. Перед удалением проверяются исходный SHA-256 и та же сигнатура; это не подтверждает, что сама сигнатура не ошиблась.
- Базы, настройки и журналы сохраняются в `%LOCALAPPDATA%\ProtectionScanner`.

Подробнее: [ClamAV для Windows](https://docs.clamav.net/faq/faq-win32.html), [сканирование ClamAV](https://docs.clamav.net/manual/Usage/Scanning.html), [обновление баз](https://docs.clamav.net/manual/Usage/SignatureManagement.html).
